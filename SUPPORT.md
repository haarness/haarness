# Getting help

- **Documentation**: <https://haarness.ai/docs>, and the engineering docs indexed in [`docs/README.md`](docs/README.md).
- **Diagnose first**: `haarness doctor` checks the install, the bundled tools and your providers.
- **Bugs and feature requests**: open an issue using the templates on this repository.
  Search existing issues first.
- **Security problems**: never in a public issue — see [SECURITY.md](SECURITY.md).
- **Haarness Cloud accounts and billing**: admin@haarness.ai.

Issues are handled on a best-effort basis by the maintainers; there is no guaranteed
response time for the open-source project.
