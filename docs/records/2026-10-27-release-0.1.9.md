# 2026-10-27 Release 0.1.9: new command names, plain wording, one release on haarness.ai

0.1.9 renames commands and settings and rewrites wording across the products: `/approvals` switches the approval
mode, the lowest configuration layer is the system folder (`HAARNESS_SYSTEM_CONFIG_DIR`), `haarness stats` and
`insights` take `--here`, `haarness prompt customize` copies a built-in prompt (its header records
`written-from`), and `haarness profile push|search|info|download|pull|delete` talk to a profile catalog. Auto's
reviewer prompt, the queue and review labels and many messages read in new words in every language. The Desktop
HTML preview and the tool-row selection check were rewritten. After the release, every earlier release was
removed from haarness.ai, so 0.1.9 is the only one there.

## Release

Source d04b26bc (tag v0.1.9), stable channel, release ID 01a17c39-3e25-728f-8469-14ba318daeae; GitHub release with
19 assets, sizes and SHA-256 verified. Gate: Rust workspace tests, clippy, fmt, architecture, Desktop typecheck and
633 unit tests, SDK gate (schema, both SDKs, packed artifacts), `test-release-publish.py`, the boundary check. All
six platforms built on this Mac (macOS signed, notarized and stapled; Linux and Windows in Docker, Windows unsigned
as before), with the platform checks passing.

End to end before the release: the full Desktop Playwright suite (428 passed; the failures left are the same on the
previous main: an invalid-path message, the "Download updates automatically" search entry, a missing-file toast),
the Chrome extension suite (50 passed, fake bridge and full stack), the browser driver and its contract, and the TUI
tmux scripts (the ones that fail fail the same way on the previous main).

Cloud 20261027-e93c747 with workspace image 20261027-d04b26b-e93c747, staging then prod; the public docs carry the
new names.

## 0.1.8 → 0.1.9 on production, after the cleanup

- **macOS**: a signed 0.1.8 app launched through LaunchServices offered Restart to update, installed 0.1.9 and
  reopened (`install result ok`).
- **Linux**: `FROM_VERSION=0.1.8 scripts/test-linux-update.sh` replaced the AppImage in place and ran 0.1.9.
- **TUI**: the 0.1.8 CLI showed the notice on its home screen and `haarness --update` installed 0.1.9.

## One release on haarness.ai

The 11 earlier release records (stable 0.1.1–0.1.8, two 0.1.3 previews) and their 140 files were deleted: the rows
from the release tables and the files from both buckets (each now answers 404, also from the edge). The release
history lists 0.1.9 only, the preview channel is empty, and asking `install.sh` for an earlier version is refused.
A data-only dump of the three release tables from before was kept outside the repositories.
