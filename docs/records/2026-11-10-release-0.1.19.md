# 2026-11-10 Release 0.1.19: provider fixes, small local models' tool calls, and plainer refusals

0.1.19 carries the provider and local-model fixes that landed after 0.1.18: chats with Claude, OpenAI, Groq, Gemini's
OpenAI-compatible address, custom endpoints and Ollama that failed or misread a turn now go on, and refusals say what
happened in plain words. The phones are not part of this release.

## What changed

- **Claude**: a chat no longer fails after Claude says what it will do before a tool call; its reasoning is kept across
  those tool calls.
- **OpenAI**: refusals say what happened, and short waits the service asks for are sat out instead of failing the turn.
- **Groq**: its own model list says which models take tools, so only those are offered tools; its limits read in plain
  words. A day of tokens used up says when it comes back, and a request over the account's tokens a minute is sent
  again with the project's tools.
- **Custom endpoints**: a provider's error words are kept (also when sent as a list of one), and a chat goes on after
  tool calls and after a failed turn. Gemini through its OpenAI-compatible address keeps working after a tool call.
- **Small local models**: file and search tools accept the calls small models make; `execute` is offered only when the
  chat has a tool it can call; gpt-oss changes files with edit and write; a new Ollama chat no longer starts on a model
  that writes its tool calls as text, and an Ollama reply ends when it fills the context instead of running on.
- **Subagents** count within the chat and the turn that started them.
- **Haarness Cloud**: credit refusals read as the advice they are, not as a provider error.
- **Router** 0.1.19: a chat with Claude through the router no longer fails after Claude says what it will do before a
  tool call (Cloud has run this since 2026-11-09). **Cloud**: Haarness 0.1.19 in Cloud workspaces, router 0.1.19.
