# 2026-11-01 Release 0.1.15: model lists that follow each provider, local models, and a Screenshots dialog that scrolls

0.1.15 gathers two days of work on the CLI, the terminal UI, Desktop and Haarness Router. Model lists now come from
each provider's live catalog, local models run through Ollama and LM Studio, xAI, DeepSeek, OpenRouter, Bedrock and
GitHub Copilot work end to end, and Desktop's Screenshots dialog no longer squeezes a full folder into empty strips.

## What changed

- **Models**: every provider's list follows its live catalog (OpenAI, Claude, Gemini, xAI, Azure, Vertex, Copilot and
  the compatible presets). A level a catalog lists is accepted, a new version never borrows another version's price or
  limits, a retired model says so plainly, and a chat with no model gets one from the lists.
- **Local models**: Ollama and LM Studio, one model at a time. LM Studio loads models with room for an agent and offers
  their own reasoning levels; a chat keeps working when a local model can't read images or its runtime stops; a runtime
  started later is found.
- **Providers**: xAI (its chat models, images, levels and prices), DeepSeek (directly and behind Haarness Router),
  OpenRouter (credit-limited output, charged costs, upstream errors), Bedrock (streams, lists the account's models,
  explains a new account's refusals), GitHub Copilot (Haarness's own GitHub app, every model its catalog lists). A
  provider account out of credit says where to top up; short rate limits are waited out in the provider's words.
- **Turns**: a stopped answer keeps what streamed before the stop; a tool call's result follows the call; a model's
  reasoning goes back to that model alone; a refused forced tool call is asked again unforced.
- **Desktop**: the Screenshots dialog scrolls a folder with more screenshots than fit, so every preview and name shows
  whole (a full folder used to squeeze each tile into an empty-looking strip); a new chat is centred with its message
  box; a window whose page stops reloads by itself and `desktop.log` says why; the sidebar's account row is one line.
- **Terminal UI**: a local model is named on the home screen as the picker names it.
- **Windows**: plain paths, programs found by PATHEXT, `haarness run "prompt"` no longer waits on an idle stdin, an
  8 MiB main-thread stack; the Rust suite and Desktop tests pass there in CI.
- **Router**: 0.1.15 (version only; its live-catalog model lists shipped on its main before this).
- **Cloud**: the router lock follows 0.1.15, and the deploy carried other sessions' pushed Cloud work (website download
  counts per campaign source, Home offering Haarness on your own computer, link-only email checks).
